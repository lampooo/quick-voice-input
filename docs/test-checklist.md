# 实测清单

每一项都按「长按 → 说一句话 → 松开」操作，记录下面的结果（网易叭哥说是「点按开始、点按结束」，见专门一节）：

- **触发**：约 0.5 秒后菜单栏图标变成实心麦克风，输入法开始录音
- **上屏**：松开后文字出现在光标处，没有多出字符；菜单里「最近一次」显示「已上屏 N 个字符」
- **副作用**：没有误选中文字、没有额外点击、没有弹出菜单，松开后 Option / Command 键没有「卡住」

## 准备

- [ ] 「辅助功能」里已打开「快捷语音输入」
- [ ] 设置向导里的按钮、下拉框都能点（「下一步」「开始测试…的语音快捷键」等）
- [ ] 第 2 步列出了微信输入法、豆包输入法和网易叭哥说的安装情况和语音快捷键（叭哥说标注为独立 App、点按开始/结束）
- [ ] 第 3 步每个输入法都选「跟随…」，显示的键和输入法里的「按住说话」一致（推荐微信输入法用右 Option，豆包输入法用右 Command）
- [ ] 在输入法里改一次「按住说话」，不重启快捷语音输入，下一次长按就按住新的键（日志 `holding hotkey …` 一行）
- [ ] 「开始测试…的语音快捷键」显示当前生效的键可用，并记录「按住多少秒后开始录音」；两个输入法分别测一次
- [ ] 手动指定时，「录制快捷键…」能录入任意组合（例如左 Option + 空格），带普通键时有风险提示
- [ ] 向导第 4 步的测试输入框能正常上屏，松开鼠标后录音马上停止，下方显示「上一次长按：已上屏 N 个字符」

| 场景 | 预期 | 结果 |
| --- | --- | --- |

| 「自动」+ 当前是豆包输入法 | 按住豆包输入法的键（右 Command），不切换输入法 |  |

## 网易叭哥说（点按开始 / 点按结束）

叭哥说是独立 App，不是输入法：不切换输入法，在任何输入法下都能用。测试前先在叭哥说「设置 → 快捷键」里确认语音快捷键（可以是单独的左 Command，也可以是左 Command + 左 Control + L 这类组合，应用会跟着它变），菜单栏的状态要显示「网易叭哥说：点按…」。

| 场景 | 预期 | 结果 |
| --- | --- | --- |
| 备忘录里长按，说一句，松开 | 约 0.5 秒后叭哥说开始录音，松开后马上结束，文字上屏，没有多出字符，没有「卡」在录音状态 |  |
| 长按不到 0.5 秒就松开 | 什么都不发生，叭哥说没有录音 |  |
| 刚触发就松开（0.5 秒左右） | 不会一直录下去：麦克风已起来就补一次结束点按；还没起来就在 4 秒内盯着，起来了立刻结束（日志里有 `the microphone started late`） |  |
| 说 30 秒以上再松开 | 松开后正常结束 |  |
| 叭哥说已经在录音（自己点按过）时长按 | 提示「麦克风正被占用」，不补发点按，不会把它关掉 |  |
| 长按之前按住了别的键（例如 ⌘C 刚按完就长按） | 等键盘空闲再发点按；一直不空闲就放弃，不乱发 |  |
| 录音过程中自己按真实的 ⌘C 等组合键 | 实测记录：叭哥说是否被误结束或误触发；松开时仍按麦克风状态确认，只在确实还在录音时补点按 |  |
| 连续两次长按，间隔很短 | 两次点按之间至少隔 0.8 秒，不会被叭哥说当成双击 |  |
| 录音中叭哥说自己结束了（例如它的超时） | 松开时不再多发一次点按，日志写 `the microphone had already stopped` |  |
| 录音中退出「快捷语音输入」 | 先补发结束点按再退出；Command 键没有卡住；叭哥说没有一直录 |  |
| 录音中强制结束「快捷语音输入」后重新启动 | 启动时发现遗留记录，检查麦克风，必要时补发一次结束点按，并清除记录 |  |
| 补发之后叭哥说仍在录音 | 菜单栏图标变成三角警告，响一声提示，菜单里写明手动点叭哥说结束；点一次叭哥说后恢复 |  |
| 在叭哥说里把快捷键改成别的（单键、带 Fn 的组合、鼠标键） | 不重启，下一次长按用新的键；鼠标键、Fn 组合会提示「暂时点按…」或明确说明做不到 |  |
| 快捷键是组合（左 Command + 左 Control + L） | 能按组合发点按；松开后 Command、Control 没有卡住 |  |
| 快捷键是单独的左 Command，微信输入法正在选候选词 | 向导和菜单里出现「Command 候选选择」冲突提示 |  |
| 「测试语音快捷键」 | 完整点按开始、监听 1.5 秒、再点按结束；结果显示「开始约 N 毫秒、结束约 M 毫秒」，不会留下录音 |  |
| 在叭哥说自己的窗口里长按 | 不触发 |  |
| 点按时长默认 100 毫秒；若叭哥说没反应 | 用 `defaults write com.quickvoiceinput.app tapHoldMs -int 150` 加长再试 |  |

## 不应该触发的情况

- [ ] 快速单击、双击、三击：和平时一样
- [ ] 按住拖选文字：正常选中，不触发
- [ ] 按住 ⌘ / ⌥ / ⌃ / ⇧ 再长按：不触发
- [ ] 在按钮、网页空白处、Finder 文件上长按：不触发
- [ ] 密码框里长按：不触发
- [ ] 菜单栏里点「暂停长按语音输入」后长按：不触发
- [ ] 在某个软件里点菜单栏「在〈当前软件〉中屏蔽」后长按：不触发；再点「取消屏蔽」后恢复
- [ ] 设置窗口「屏蔽的软件」：从正在运行的软件添加、从「应用程序」文件夹添加 .app、移除，列表显示图标和名称
- [ ] 屏蔽后，菜单「在〈当前软件〉中」的规则显示为「不触发（屏蔽）」，两边始终一致

## 边界情况

- [ ] 长按说话时移动鼠标：不会选中文字，松开后正常上屏
- [ ] 刚触发就立刻松开：不卡键，不多出字符
- [ ] 说很长一段话（30 秒以上）：松开后正常结束
- [ ] 原本是英文输入法（ABC）：会自动切到语音输入法，并能上屏
- [ ] 用触控板：触发时有轻微震动；按得更重也不会弹出「查询」
- [ ] 录音时退出「快捷语音输入」：Option / Command 键不卡住
- [ ] 单独按住左 Option 超过 1 秒：记录会不会也触发语音（判断微信输入法是否严格区分左右）
- [ ] 豆包输入法：刚触发就立刻松开，豆包没有变成「按一次开始说话」一直录下去
- [ ] 在微信输入法、豆包输入法或网易叭哥说自己的设置窗口里长按：不触发（避免把快捷键录进它的快捷键框）
