# 实测清单

每一项都按「长按 → 说一句话 → 松开」操作，记录下面的结果：

- **触发**：约 0.5 秒后菜单栏图标变成实心麦克风，微信输入法开始录音
- **上屏**：松开后文字出现在光标处，没有多出字符
- **副作用**：没有误选中文字、没有额外点击、没有弹出菜单，松开后 Option 键没有「卡住」

## 准备

- [ ] 「辅助功能」里已打开「快捷语音输入」
- [ ] 微信输入法的「按住说话」已改成「右 Option」
- [ ] 设置向导里的「开始测试语音快捷键」显示「右 Option」可用，并记录「按住多少秒后开始录音」
- [ ] 向导第 4 步的测试输入框能正常上屏

## 常用应用

| 场景 | 触发 | 上屏 | 副作用 | 备注 |
| --- | --- | --- | --- | --- |
| 备忘录：正文中间 |  |  |  |  |
| Safari：网页搜索框、多行评论框 |  |  |  |  |
| Chrome：地址栏、网页输入框 |  |  |  | 第一次可能要多按一次（Chrome 刚开启辅助功能） |
| 微信：聊天输入框 |  |  |  |  |
| 飞书 / VS Code（编辑器、聊天框） |  |  |  | 识别不出时把该应用设成「任意位置都触发」 |
| 终端（Terminal / iTerm2） |  |  |  | 默认「任意位置都触发」；微信输入法 2.2.3 有终端上屏异常的反馈 |

## 不应该触发的情况

- [ ] 快速单击、双击、三击：和平时一样
- [ ] 按住拖选文字：正常选中，不触发
- [ ] 按住 ⌘ / ⌥ / ⌃ / ⇧ 再长按：不触发
- [ ] 在按钮、网页空白处、Finder 文件上长按：不触发
- [ ] 密码框里长按：不触发
- [ ] 菜单栏里点「暂停长按语音输入」后长按：不触发

## 边界情况

- [ ] 长按说话时移动鼠标：不会选中文字，松开后正常上屏
- [ ] 刚触发就立刻松开：不卡键，不多出字符
- [ ] 说很长一段话（30 秒以上）：松开后正常结束
- [ ] 原本是英文输入法（ABC）：会自动切到微信输入法，并能上屏
- [ ] 用触控板：触发时有轻微震动；按得更重也不会弹出「查询」
- [ ] 录音时退出「快捷语音输入」：Option 键不卡住
- [ ] 单独按住左 Option 超过 1 秒：记录会不会也触发语音（判断微信输入法是否严格区分左右）

## 反馈时请附上

- 在终端运行 `~/Applications/快捷语音输入.app/Contents/MacOS/QuickVoice --self-check` 的输出
- 菜单栏「打开日志文件夹」里的 `quickvoice.log`（只记录应用名、控件类型和耗时，不记录输入内容）
